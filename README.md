# Metaloprerada Rajevic - Web Sajt

Profesionalni website za Metalopreredu Rajevic izgrađen sa HTML5, CSS3 i JavaScript.

## 📁 Struktura projekta

```
├── index.html      # Glavna HTML stranica
├── style.css       # CSS stilovi
├── script.js       # JavaScript funkcionalnost
├── README.md       # Ovaj fajl
└── .gitignore      # Git ignore fajl
```

## 🚀 Kako pokrenuti

1. Otvori `index.html` u web pregledniku
2. Ili koristi Live Server ekstenziju u VS Code-u

## 📝 Što trebam da izmijenim

- **Naslove i tekstove** - Ažuriraj sadržaj prema tvojim potrebama
- **Boje** - Promijeni CSS varijable u `style.css` (:root sekcija)
- **Slike** - Dodaj slike u folder i uredi HTML
- **Usluge** - Dodaj sve usluge u "services" sekciju
- **Kontakt** - Integriraj backend za slanje emaila (PHP, Node.js, itd.)

## 🎨 CSS Varijable (lako se mogu promijeniti)

```css
--primary-color: #2c3e50;  /* Glavna boja */
--accent-color: #e74c3c;   /* Boja akcenata */
--text-color: #333;        /* Boja teksta */
--light-bg: #ecf0f1;       /* Svjetla pozadina */
```

## 📱 Responsive

Sajt je ful responsive i radi na svim uređajima (desktop, tablet, mobilni).
